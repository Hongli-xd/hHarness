# 史料可信度指南（历史地理学版）

## 适用范围

本指南服务于 HistRAG 的历史地理学研究任务，核心关注地点对象及其时空关系（地名沿革、政区隶属、治所迁移、边界变化、路线网络等），不是一般性文献分类。

## 可信度总原则

1. 一手史料优先于二手研究。
2. 与地点对象时空关系直接相关的证据优先。
3. 同类证据中，优先采用成体系、可核验、可定位的材料。
4. 证据不足时必须标注不确定性，不得强行定论。

## 一手史料分级

### 总体优先序（高到低）

1. 考古材料
2. 金石材料
3. 档案材料
4. 史书与传世文献

### 一手史料细分规则

1. 考古材料（最高优先）
- 例：遗址、墓葬、出土简牍、实物遗存、地层与测年信息。
- 适用：地点定位、聚落分布、路线遗存、边界与环境变迁。

2. 金石材料（高优先）
- 例：碑刻、墓志、摩崖、钟鼎铭文。
- 适用：地名、建置、交通节点、人物活动地点的时地锚定。

3. 档案材料（中高优先）
- 官方档案优先于个人档案。
- 官方档案：奏折、公文、题本、诏令、册档、政府调查册等。
- 个人档案：家书、日记、私人文书、个人账簿等。

4. 史书与传世文献（中优先到低优先）
- 正史记载优先级最高。
- 其次为方志资料、地理志资料、历代地图志（如《元和郡县图志》）。
- 再次为重要传世文献（如《资治通鉴》）。
- 最后为游记、诗词等文学性材料（仅作旁证，不可单独定论）。

## 二手研究分级

### 使用原则

1. 二手研究用于解释、对比与争议梳理，不替代关键一手证据。
2. 二手研究必须能回溯其一手依据。
3. 与历史地理方法直接相关的研究（空间分析、对比研究、地图与文本互证）优先。

### 二手研究优先序（高到低）

1. 学术专著（严格筛选）
- 仅保留经典名著、知名学者、权威出版社成果。
- 出版社优先：商务印书馆、中华书局等。
- 学者示例：谭其骧、史念海、侯仁之、周振鹤、韩茂莉、蓝勇等。

2. 期刊论文（必须核心/权威）
- 必须来自核心期刊或权威期刊（如 CSSCI 来源、北大核心等）。
- 历史地理方向可优先关注：
- 《中国历史地理论丛》
- 《历史地理研究》（原《历史地理》）
- 《中国边疆史地研究》

3. 教科书（默认不使用）
- 非必要不使用教科书。
- 如必须使用，仅限大学阶段指定教材或高质量专业教材。
- 明确排除中学教科书。

## 排除与降权规则

1. 无明确来源、无出处页码、无可追溯版本的信息直接降权。
2. 与研究时段不匹配、将现代地理概念直接投射古代语境的论证直接降权。
3. 仅基于游记、诗词或网络转载形成的地点结论，不得作为高可信结论。
4. 商业征稿站、非学术聚合页信息不得作为学术依据。

## 争议性说法处理

1. 必须并列呈现主要解释路径及其证据链。
2. 明确区分“事实层”“解释层”“推测层”。
3. 不能裁剪不利证据，不得以单一二手观点压制其他主流解释。

## 标注规范

### 何时标注

1. 每个关键事实主张都要标注来源。
2. 涉及地点对象时，必须标注时间范围与空间对象。
3. 争议性主张必须标注为争议，并列出主要分歧依据。

### 如何标注

使用 `cite` 工具：
```text
claim: [历史地理主张]
credibility: [primary/secondary/disputed]
tier: [P1/P2/P3/P4 或 S1/S2/S3]
source_entities: [相关来源]
time_scope: [时代或具体年份]
space_scope: [地点对象/政区/路线]
notes: [证据说明与不确定性]
```

## 输出前核查清单

1. ✅ 是否以地点对象及其时空关系为中心？
2. ✅ 是否优先使用了高等级一手史料？
3. ✅ 二手研究是否来自核心/权威来源并可追溯？
4. ✅ 是否存在同名异地、异名同地、治所迁移等歧义未处理？
5. ✅ 是否清楚标注证据等级、时代范围与空间范围？
