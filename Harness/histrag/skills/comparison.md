# 比较法 (Comparative Method)

## 适用场景

在以下情况下使用比较法：
- 比较不同社会的历史现象
- 分析案例之间的异同
- 试图识别模式或独特发展
- 检验关于历史因果的假设

## 核心原则

1. **可比性 (Comparability)**：确保案例真正可比
2. **对等性 (Equivalence)**：使用对等的类别和时间段
3. **系统性 (Systematicity)**：系统地比较，而非选择性比较
4. **语境化 (Contextualization)**：在语境中解释差异

## 工作流程

### 1. 界定比较范围

```
A. 选择要比较的案例
B. 确定比较的维度
C. 设定时间段
D. 阐明驱动比较的问题
```

### 2. 收集证据

```
对每个案例：
- 背景条件
- 关键行为者/事件
- 过程/机制
- 结果
```

### 3. 系统比较

| 维度 | 案例A | 案例B | 相似点 | 差异点 |
|------|-------|-------|--------|--------|
| 政治 | ... | ... | ... | ... |
| 经济 | ... | ... | ... | ... |
| 社会 | ... | ... | ... | ... |
| 文化 | ... | ... | ... | ... |

### 4. 解释结果

- 如何解释相似点？
- 如何解释差异点？
- 模式是否支持或挑战现有理论？

## 应用示例

比较汉帝国与罗马帝国的崩溃：

```
问题：为何汉与罗马帝国都面临相似的内部压力？

相似点：
- 土地集中
- 农民贫困化
- 蛮族在边疆的压力
- 军事过度扩张

差异点：
- 中国：更早重新统一（隋/唐）
- 罗马：更长时间的分立（拜占庭/西罗马分裂）

可能解释：
- 地理因素（草原地理）
- 儒家与罗马意识形态框架的差异
- 官僚制与元老院制治理结构的差异
```

## 关键注意事项

### 选择偏差
注意不要选择支持预设结论的案例。

### 虚假对等
确保跨案例的类别真正对等。

### 复杂性
真实案例是复杂的；避免过度简化。

## 局限性

1. 比较可能掩盖个别案例的独特特征
2. "最相似体系"设计有固有局限
3. 跨文化比较有将西方范畴强加于人的风险
